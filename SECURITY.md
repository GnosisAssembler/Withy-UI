# Security policy

## Supported versions

Security fixes are shipped on the latest 0.x release of `withy-ui`.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/GnosisAssembler/Withy-UI/security/advisories/new). Do not open a public issue for a security problem.

Include the package version, the affected component or workflow, and a short description of the impact. We will acknowledge the report and follow up with a fix or a reasoned dismissal.
